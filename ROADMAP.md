# ROADMAP — TShock Server Suite

> **Phase 4 of the side-hustle year (Aug – Oct 2027). The deliberate outlier: different audience, smaller but passionate. Holiday-season timing.**
> Master plan lives in the home repo: side-hustle-master-plan.md

**Goal:** merge the TShock plugin family into one product:

| Repo | Role |
|---|---|
| Metatron (this repo) | all-in-one core — the suite's installer and glue |
| Herald | events & communication engine |
| Cerberus | Discord role-based access |
| Chronical | stateful gameplay |
| **Havoc** | **the flagship:** stream viewers interact with the live server |

**Positioning:** "One install, and your Terraria server becomes a show."
Havoc pitches itself to streamers; the suite sells to server owners.

## Rules

Same as the master plan: plugins run on the user's server = zero marginal cost,
AI for development only, one-time per-server licenses, ≤ 2 hrs/week maintenance.

## Quarter plan

**Month 1 (Aug 2027)**
- [ ] Consolidate: single installer + shared config, one docs site, brand the suite

**Month 2 (Sep 2027)**
- [ ] Havoc v1 polish
- [ ] Streamer outreach: pitch 10 Terraria streamers directly; free licenses for feedback

**Month 3 (Oct 2027)**
- [ ] Sell: one-time license per server; marketplace listing for discovery + direct license keys for margin (Tebex-style merchant of record handles payments and fraud)
- [ ] Holiday launch; year-end review of all four phases

## Pricing sketch

- Suite core: free
- Pro modules: $19.99 one-time per server
- Havoc standalone: free for sub-only channels — goodwill + distribution

## Honesty section

This is the smallest market of the four. If earlier phases underperformed, **this phase is optional.**
One strong product beats five shells. Decide at the Phase 3 gate, and again here in October.
